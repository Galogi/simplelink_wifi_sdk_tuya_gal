Migration from 9.13.01.14 |rarr| 9.20.00.07
==========================================

This page will go over the main changes between SDK version 9.13.01.14 and 9.20.00.07

CCS
---

The SDK now works with the latest CCS 20.3.
This provides a more seamless experience as no patching is necessary.

Examples
--------

Networking examples are now located under `examples/rtos/LP_EM_CC35X1/demos`.

Wlan Driver
-----------

conf_cc35xx.h has been renamed to conf.h
