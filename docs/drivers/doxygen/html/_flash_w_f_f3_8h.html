BITMASK_x_0(5) = ........111111 Bits[5:0] = "111111" BITMASK_x_0(0) = .............1 Bits[0:0] = "000001"

BITMASK_x_y() returns a bit mask of "1" from Bits[x:y] (naturally, x >= y should be enforces by the caller!!)
